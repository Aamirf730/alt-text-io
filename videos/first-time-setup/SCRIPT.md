# Alt Text Pro: First-Time Setup

**Format:** caption-led product walkthrough  
**Length:** about 54 seconds  
**Audience:** WordPress users installing Alt Text Pro for the first time

| Time | On-screen action | Narration / captions |
| --- | --- | --- |
| 0:00–0:04 | Alt Text Pro title card | “Welcome to Alt Text Pro. Let’s get your plugin connected in under a minute.” |
| 0:04–0:10 | Show the connection screen in WordPress | “After activation, open Alt Text Pro in your WordPress dashboard. The connection screen appears automatically.” |
| 0:10–0:19 | Highlight **Connect Account** | “The quickest option is Connect Account. Sign in, or create your free Alt Text Pro account.” |
| 0:19–0:28 | Show a browser-style connection confirmation | “Complete the secure sign-in in your browser. Your plugin receives its API key automatically—there’s nothing to copy.” |
| 0:28–0:38 | Highlight the manual API-key field | “Prefer to connect manually? Open your Alt Text Pro dashboard, copy your API key, and paste it here.” |
| 0:38–0:46 | Highlight **Save API Key**, then show a success state | “Choose Save API Key. Your key is stored securely and is never shared.” |
| 0:46–0:54 | Show the connected dashboard state | “That’s it. Alt Text Pro is ready to generate accurate image alt text for your WordPress media library.” |

## Production notes

- Use teal `#0D4F5E` as the primary accent.
- Keep every caption visible for at least three seconds.
- The video is deliberately caption-led and has no baked-in voiceover, so it can be shared silently or paired with a recorded narration later.
