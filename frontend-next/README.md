# Alt Text Pro - Next.js Dashboard

This directory contains the modernized frontend for Alt Text Pro, built with Next.js 14 and the App Router.

## 🚀 Key Features
*   **App Router**: Modern React patterns for routing and server components.
*   **Supabase Auth**: Integrated authentication flow (Login, Signup, Magic Links).
*   **Polar.sh Subscriptions**: Native integration with Polar.sh for billing and checkout.
*   **Shadcn/UI**: Premium, accessible component library based on Radix UI.
*   **Tailwind CSS**: Utility-first styling for high performance and responsiveness.

## 🛠️ Performance & SEO
*   **Optimized Images**: Utilizing `next/image` for automatic optimization.
*   **SEO Metadata**: Dynamic metadata generation for landing and dashboard pages.
*   **Lighthouse Optimized**: Built for speed and accessibility.

## 💻 Development

1.  **Setup Environment**:
    ```bash
    cp .env.local.example .env.local
    ```
2.  **Install Dependencies**:
    ```bash
    npm install
    ```
3.  **Run Development Server**:
    ```bash
    npm run dev
    ```

For full system architecture and deployment guides, please refer to the [root documentation](../TECHNICAL_OVERVIEW.md).
