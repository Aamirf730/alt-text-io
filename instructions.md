# Codex Navigation

Before making changes:

1. Read `AGENTS.md`, then `PROJECT.md` and `progress.md`.
2. Run `scripts/ai-context.sh`.
3. Read `phases/README.md` and the phase relevant to the task.
4. Read `RELEASE_CHECKLIST.md` before any release, deployment, or migration task.
5. Update `progress.md` whenever work starts, changes state, completes, or encounters an issue.
6. Keep secrets and generated dependencies out of Git. Do not mutate live Supabase, Netlify, or WordPress production systems without explicit scoped approval.
