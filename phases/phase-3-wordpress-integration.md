# Phase 3: WordPress Integration

## Scope and deliverables

Maintain the WordPress plugin in `wordpress-plugin/alt-text-pro`, its Netlify API contracts, generation workflows, packaging, and upgrade compatibility.

## Dependencies

Stable API, auth, and usage contracts from Phase 1.

## Tests

Run PHP syntax checks, plugin-focused tests, API contract tests, and verify the generated plugin ZIP before release.

## Acceptance and exit gate

Plugin and backend versions agree, authentication and quota behavior are correct, package integrity is verified, and upgrade paths preserve user settings.
