# Phase 2: Customer Application

## Scope and deliverables

Maintain the Next.js application in `frontend-next`, including authentication, onboarding, dashboard, account, billing, invitation-only customer offers, and accessible user workflows.

Public editorial content: publish the alt-text writing guide covering all eight requested topics (accessibility, best practices, captions, SEO, tools, screen readers, description examples and usability). Include original examples, primary sources, article metadata, internal discovery links and sitemap coverage. Article prose uses no semicolons or long dashes. Verify rendered content, desktop/mobile layout, metadata, links, typecheck, lint and production build before the Phase 4 publication handoff. Organic search traffic is an observation metric, not a guaranteed release outcome.

## Dependencies

Stable platform contracts from Phase 1.

## Tests

Run lint, type checks, focused component or route tests, and a production build when application code changes.

## Acceptance and exit gate

Core customer journeys and invited-offer claim states work across supported viewports, error states are clear, accessibility remains intact, private campaign pages are not indexed, and the production build succeeds.
