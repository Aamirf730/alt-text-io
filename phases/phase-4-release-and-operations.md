# Phase 4: Release and Operations

## Scope and deliverables

Coordinate release branches, verification, private GitHub backups, deployment readiness, external archives, restore instructions, and operational records.

## Dependencies

Accepted deliverables from the relevant implementation phases.

## Tests

Run risk-proportionate test suites, confirm a clean source snapshot, verify remote reachability, test archives with `unzip -t`, and record SHA-256 checksums.

## Acceptance and exit gate

Required checks pass, source is remotely recoverable, archives are independently verified, release notes and progress evidence are current, and production changes have explicit authorization.
